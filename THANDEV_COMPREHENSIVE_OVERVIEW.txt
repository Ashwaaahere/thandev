# THANDEV - COMPREHENSIVE WEB APPLICATION OVERVIEW
# =====================================================

## PROJECT SUMMARY
==================

Thandev is a modern, futuristic security intelligence platform that provides real-time CVE (Common Vulnerabilities and Exposures) data, exploit feeds, security news, and comprehensive website security & performance scanning capabilities. It's a full-stack web application built with Next.js frontend and FastAPI backend, featuring advanced security scanning tools and real-time data ingestion.

## ARCHITECTURE OVERVIEW
========================

### Technology Stack
- **Frontend**: Next.js 14, TypeScript, Tailwind CSS, Framer Motion
- **Backend**: FastAPI, Python 3.11+, SQLAlchemy, PostgreSQL
- **Database**: PostgreSQL 15+ with Redis for caching
- **Cloud Infrastructure**: Google Cloud Run, Vercel, Fly.io
- **Security Tools**: Nuclei, Nmap, SSLScan, Google Lighthouse
- **Authentication**: NextAuth.js with multiple providers

class Exploit(Base):
