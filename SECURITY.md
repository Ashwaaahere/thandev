# Security Policy

## Reporting a Vulnerability
Please email the maintainers privately with details and a proof-of-concept if possible.
We will acknowledge receipt within 48 hours and keep you informed of the triage status.

- Primary contact: security@thandev.dev (placeholder)

## Supported Versions
This is an MVP under rapid development; security fixes target the `main` branch.

## Program
We run **CodeQL** on every PR and Dependabot for dependency updates.
